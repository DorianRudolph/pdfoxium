# C API font fixtures

`Cantarell-VF-ABC.otf` is the unchanged 2,508-byte CFF2 variable-font subset
from Fontations/Skera test data, pinned to commit
`cf5676b29faa8c7787abe003c5dfb85fd81e8a7c`:

https://github.com/googlefonts/fontations/blob/cf5676b29faa8c7787abe003c5dfb85fd81e8a7c/skera/test-data/fonts/Cantarell-VF-ABC.otf

SHA-256: `150ba8a209281293f335a1500e3030f89038d98578954577d7670548fdae0ff8`.

The source test-data README identifies the fonts as SIL Open Font License 1.1:
https://github.com/googlefonts/fontations/blob/cf5676b29faa8c7787abe003c5dfb85fd81e8a7c/skera/test-data/README.md

The font's embedded copyright is retained at the top of `Cantarell-OFL.txt`;
the license text comes from the Cantarell distribution in Google Fonts.
This is test data only. Production uses the published Skera dependency.
